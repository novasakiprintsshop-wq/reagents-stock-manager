# Reagent Stock Manager V1

Standalone Atellica reagent stock control app.

## Separation from Novasaki Order Manager
- Separate GitHub repository.
- Separate browser storage key: `REAGENT_STOCK_MANAGER_V1_DATA`.
- No Novasaki Order Manager data is read or written.

## V1 features
- Reagent master list
- Stock IN / Stock OUT
- Current balance
- Lot number and expiry
- Minimum-stock warning
- Expiry warning
- Movement history
- JSON backup/restore
- Installable PWA

## Important
Data is stored locally in the browser/device. Use **Backup & Restore** before clearing browser/site data or changing devices.
